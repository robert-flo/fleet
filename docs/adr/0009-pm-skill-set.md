# PM skill set

Which skills a PM uses, decided 2026-09-30:

- `/ask-matt` is the PM's map of how to operate.
- `/wayfinder` is for when there is no repo yet, to sharpen the idea.
- `/grill-with-docs` is for when a repo and a route exist, to turn the conversation into spec and tickets.
- `/to-spec` and `/to-tickets` as in ADR 0008.
- `/prototype` is the one exception to "the PM never changes code": throwaway code on a `prototype/<name>` branch, never production code.
- `/triage` is not used.
- `/implement`, `/implement-spec`, `/tdd`, `/code-review` and `/retro` belong to Etapa 2.
