# 0026 — workstation: TickTick orquesta, GitHub Issues solo specs

Fecha: 2026-10-25 · Estado: aceptado

## Contexto
Roberto crea el proyecto workstation (hub robert-flo/PJ-NIRI-rf-omarchy-workstation) para unificar su infraestructura, que hoy está repartida en 114 repos con cuatro hubs que compiten. Linear (ADR 0025) ya no se usa.

## Decisión
1. Para workstation, TickTick (lista `workstation`, grupo `workstation`) orquesta el trabajo con las columnas Inbox, Understand, Design, Build, Deploy e Improve, y GitHub Issues guarda solo specs y sub-issues. Esto reemplaza ADR 0025 para este proyecto.
2. workstation es la infraestructura y Domina es solo la vida de Roberto.
3. Los ADR de migración los diseñan Roberto y el CEO; el trío PM/WK/RV-workstation solo ejecuta lo decidido.
