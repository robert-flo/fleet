# TickTick kanban columns template

Every list in a PM's TickTick project group uses these kanban columns, in this order, exactly as written:

1. 🌼 MAYBE
2. 🌼 INVESTIGATING
3. 🌼 IN PROGRESS
4. 🌼 ON HOLD
5. 🌼 QA TO CONFIRM
6. 🌼 DONE

🌼 QA TO CONFIRM means all work is done and a PR is about to go up. While a PM designs, its task sits in 🌼 INVESTIGATING, and it stays there when the design is done (spec and tickets published), until Etapa 2 picks it up.

Column meanings:
- 🌼 MAYBE: ideas not yet committed to.
- 🌼 INVESTIGATING: being designed by the PM (grill, spec, tickets); stays here when design is done until execution starts.
- 🌼 IN PROGRESS: under development.
- 🌼 ON HOLD: was in development but hit a blocker or things did not go as expected; paused, or sent back to 🌼 INVESTIGATING.
- 🌼 QA TO CONFIRM: all work done, about to open a PR.
- 🌼 DONE: finished.
