# TickTick kanban columns template

Every list in a PM's TickTick project group uses these kanban columns, in this order, exactly as written:

1. 🌼 MAYBE
2. 🌼 INVESTIGATING
3. 🌼 IN PROGRESS
4. 🌼 ON HOLD
5. 🌼 QA TO CONFIRM
6. 🌼 DONE

🌼 QA TO CONFIRM means all work is done and a PR is about to go up. While a PM designs, its task sits in 🌼 INVESTIGATING, and it stays there when the design is done (spec and tickets published), until Etapa 2 picks it up.
