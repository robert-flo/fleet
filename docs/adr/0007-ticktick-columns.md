# TickTick kanban columns template

Every list in a PM's TickTick project group uses these kanban columns, in this order, exactly as written:

1. 🌼 MAYBE
2. 🌼 INVESTIGATING
3. 🌼 IN PROGRESS
4. 🌼 ON HOLD
5. 🌼 QA TO CONFIRM
6. 🌼 DONE

🌼 QA TO CONFIRM means all work is done and a PR is about to go up. The column for the PM's "review my plan" task is still open.
