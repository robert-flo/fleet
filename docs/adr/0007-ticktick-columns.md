# TickTick kanban columns template

Every list in a PM's TickTick project group uses these kanban columns, in this order, exactly as written:

1. 🌼 MAYBE
2. 🌼 INVESTIGATING
3. 🌼 IN PROGRESS
4. 🌼 ON HOLD
5. 🌼 QA TO CONFIRM
6. 🌼 DONE

The review task a PM creates when it finishes tickets goes in 🌼 QA TO CONFIRM.
