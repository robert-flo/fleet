# One PM per area does grill, spec and tickets

Each Área gets a single PM that runs grill-with-docs, to-spec and to-tickets itself, rather than three specialized agents handing off. to-spec is designed to synthesize the grill conversation without re-interviewing, so a handoff between those steps would lose exactly the context it needs, and three bots per project would roughly triple quota use. Handoffs are reserved for the jump from planning to execution.
